SUBNETEO(1)                Manual del usuario                SUBNETEO(1)

NOMBRE
    subneteo — cuaderno interactivo de subneteo IPv4

SINOPSIS
    subnet <dirección>/<prefijo>

DESCRIPCIÓN
    Calcula máscara, red, wildcard y broadcast a partir de una
    dirección IPv4 con prefijo CIDR. Modo práctica: escribís la
    respuesta en octetos y verificás, o revelás si te trabás.

OPCIONES
    Practicar          activá/desactivá qué pasos querés resolver
    Aleatorio           genera un ejercicio al azar por clase y rango
                        de prefijo
    Examen              N ejercicios con límite de tiempo opcional,
                        incluye mínimo 3 subredes consecutivas

EJEMPLOS
    $ subnet 192.168.100.170/26
        → red 192.168.100.128, broadcast 192.168.100.191, 62 hosts

VER TAMBIÉN
